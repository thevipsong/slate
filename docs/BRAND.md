# 序事品牌命名规范

## 核心命名

- 应用名称：**序事**
- 商店名称：**序事 · 极简待办**
- 英文副标题：**Slate**
- 宣传语：**记下每件事，按自己的节奏完成。**

## 使用方式

- 系统桌面、窗口标题、通知权限和日常操作文案使用“序事”。
- 商店列表、发布页面和对外推广标题使用“序事 · 极简待办”。
- “Slate”作为英文副标题，以弱于“序事”的视觉层级出现，不与中文名称并列争夺主标题。
- 宣传语用于商店简介、产品介绍和空状态，不在高频操作界面重复展示。

## 技术兼容

为保证旧版本可以直接覆盖升级且不丢失数据，以下技术标识继续保留：

- Android applicationId：`com.thevipsong.slate`
- macOS Bundle ID：`com.thevipsong.slate`
- 本地数据目录：`Slate`
- 跨端数据格式名称：`Slate v3`
- 源码中的 `Slate*` 类型名、数据库表与迁移记录

这些标识仅用于兼容和工程实现，不作为用户可见的产品主名称。
